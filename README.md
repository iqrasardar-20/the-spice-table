# 🍽️ The Spice Table - Luxury Restaurant Website

A modern and elegant restaurant website built with React and Tailwind CSS.  
The website provides a premium dining experience with smooth animations, responsive design, and interactive sections.

## 🌐 Live Demo

https://the-spice-table.vercel.app

---

## ✨ Features

- 🏠 Modern luxury restaurant homepage
- 🍽️ Featured dishes section
- 👨‍🍳 Chef introduction section
- 🖼️ Restaurant gallery
- 📅 Table reservation section
- 📩 Contact form section
- 📱 Fully responsive design
- ✨ Smooth scrolling navigation
- 🎨 Premium dark and gold theme
- ⚡ Animated UI components

---

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- JavaScript (ES6+)
- Framer Motion
- React Icons
- Vite
